# ROADMAP — Phasage

| Phase | Contenu | Critères d'acceptation | Statut |
|---|---|---|---|
| **1 — Fondations** | Stack initialisée, PostgreSQL connecté, migrations, Docker, santé, tests de base, documentation | Application compilable, démarrable, connectée à PostgreSQL ; persistance vérifiée | ✅ Terminée (2026-11-12) |
| **2 — MVP pédagogique** | Auth parent, profils enfants, dashboard enfant, tables 1..10, entraînement, défi, enregistrement des réponses | Application réellement jouable avec progression persistante vérifiée | ⬜ À commencer |
| **3 — Gamification** | Étoiles, pièces, badges, avatars, niveaux, récompenses serveur, mondes, missions | Récompenses attribuées côté serveur en transactions testées | ⬜ |
| **4 — Espace parent** | Dashboard parent, statistiques, historique, paramètres | Suivi pédagogique complet et fiable | ⬜ |
| **5 — Intelligence pédagogique** | Répétition espacée documentée/testée, détection des difficultés, adaptation | Apprentissage personnalisé fonctionnel | ⬜ |
| **6 — Optimisation** | Perf, accessibilité, responsive, E2E, sauvegardes/restauration, déploiement vérifié | Version stable documentée et déployée | ⬜ |

## Jalons de version

- v0.1.0 — Fondations (Phase 1)
- v0.2.0 — MVP pédagogique (Phase 2)
- v0.3.0 — Gamification (Phase 3)
- v0.4.0 — Espace parent (Phase 4)
- v1.0.0 — Version stable (Phase 6)

Règle : ne pas commencer une phase tant que les critères de la phase en
cours ne sont pas vérifiés et documentés.
