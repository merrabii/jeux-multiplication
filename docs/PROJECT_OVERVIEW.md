# PROJECT OVERVIEW — Royaume Magique des Multiplications

## Mission

Permettre à un enfant de 7 à 8 ans d'apprendre, comprendre, pratiquer et
mémoriser les tables de multiplication de 1 à 10, dans un univers magique
et en français, sur ordinateur, tablette et smartphone.

## Publics

- **L'enfant** : interface immersive, boutons larges, textes grands,
  pédagogie « comprendre avant de mémoriser » (ex. 3 × 4 = 3 groupes de 4).
- **Le parent** : espace distinct protégé, suivi pédagogique, paramètres,
  gestion des profils enfants.

## Principes produit

1. **Pédagogie d'abord** : représentation visuelle, addition répétée,
   révision intelligente basée sur les erreurs réelles.
2. **Motivation saine** : récompenses encourageantes, aucune humiliation,
   pas de mécanique d'addiction (pas de session infinie).
3. **Persistance fiable** : PostgreSQL est la source de vérité ; le
   navigateur ne calcule jamais les scores ni les récompenses.
4. **Protection des enfants** : minimisation des données (pseudonyme
   uniquement), pas de publicité, pas de chat, pas de partage public.
5. **Qualité vérifiable** : chaque fonctionnalité déclarée faite est
   testée et prouvée ; la documentation reflète toujours l'état réel.
